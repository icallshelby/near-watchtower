NEAR Watchtower

A network-health agent for NEAR Protocol — and an open lab around it. The agent polls live public data, scores the network from evidence, watches its own history for anomalies, and publishes a feed (data/status.json) that other agents act on (one does, below). On this page you can also re-weight the model yourself and watch the score change: the methodology is inspectable, not a black box.

Method & sources

  • NearBlocks API — supply, price, market cap, volume, lifetime transactions, nodes online, block time.
  • NEAR mainnet RPC — chain status and the live validator set; stake shares and the Nakamoto coefficient are summed directly.
  • CoinGecko — market data cross-check (price, market cap, ATH).
  • Alerts: any component under 40 flags immediately; label changes flag; with ≥5 snapshots of history, components also flag at |z| ≥ 2 against their own history.
  • Full methodology, weights rationale and limitations: the repository README. Raw responses: data/snapshot_raw.json.
Re-run the whole system yourself: python3 watchtower.py && python3 agent_consumer.py && python3 build_dashboard.py — Python 3 standard library only, no API keys.
